# 📘 Projeto Blog em React

## 📌 Sobre o projeto
Aplicação web desenvolvida com **Vue**, com navegação entre páginas utilizando componentes e controle de estado, sem uso de React Router. O projeto apresenta um blog com seção de clipping e páginas de descrição.

## 🧰 Frameworks e tecnologias utilizadas
- **React.js** – biblioteca principal para construção da interface
- **Vue.js** – Segundo Framework ultilizado para o projeto

---
### ⚠️ Principais dificuldades encontradas
- Entendimento das diferenças entre estado no React (useState) e reatividade no Vue (ref).

- Comunicação entre componentes no Vue, que utiliza props e emits, diferente do padrão direto de funções passadas no React.

- Ajustes de estrutura e organização dos arquivos de .jsx para .vue.

- Adaptação das condicionais (&& no React vs v-if no Vue)
---
### 🔍 Semelhanças e diferenças entre React e Vue 
####  Semelhanças

- Ambos utilizam componentes reutilizáveis.

- Trabalham com estado reativo.

- Permitem construção de SPAs (Single Page Applications).

- Possuem ecossistema moderno e grande comunidade.

#### Diferenças

- O React utiliza JSX e hooks como useState, enquanto o Vue utiliza templates HTML com diretivas (v-if, v-for) e reatividade com ref.

- No Vue, a separação entre template, script e style é mais explícita.

- A comunicação entre componentes no Vue segue um padrão mais estruturado com props e emits.

- O Vue apresenta uma curva de aprendizado inicial mais suave para quem vem de HTML/CSS puro.
